# DevTrack

Plataforma web para acompanhamento e análise da evolução de desenvolvedores.

## Objetivo

O DevTrack tem como objetivo permitir que desenvolvedores acompanhem sua evolução através de estudos, projetos, metas, atividades e métricas de produtividade.

## Tecnologias

- Python
- Flask
- HTML5
- CSS3
- Git
- GitHub
